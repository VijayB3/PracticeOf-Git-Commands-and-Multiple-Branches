# 🌳 Practice of Git Commands and Multiple Branches

This repository is created to practice and understand how **Git** works in real development environments.

The focus of this project is not on application code, but on mastering version control operations such as branching, merging, committing, and collaboration workflows.

---

## 📖 Project Purpose

In real companies, multiple developers work on the same project at the same time.  
To handle this efficiently, we must know:

- How to create branches  
- How to switch between branches  
- How to merge changes  
- How to resolve conflicts  
- How to maintain clean commit history  

This repository helped me gain hands-on experience with these concepts.

---

## 🎯 Learning Goals

✔ Understand distributed version control  
✔ Practice daily Git workflow  
✔ Learn branch-based development  
✔ Improve confidence in merging  
✔ Handle mistakes safely  
✔ Simulate real team scenarios  

---

## 🛠 Git Concepts Practiced

During this practice, I worked with:

- Repository initialization  
- Staging changes  
- Creating commits  
- Viewing logs  
- Creating and deleting branches  
- Switching branches  
- Merging branches  
- Conflict resolution  
- Pushing to remote  
- Pulling updates  

---

## 🔀 Branching Strategy

I created multiple branches to simulate feature-based development.

Examples:

- `main` → stable version  
- `feature-1` → new experiment  
- `bugfix` → fixing issues  
- `testing` → trying temporary changes  

This approach mirrors how teams manage development in companies.

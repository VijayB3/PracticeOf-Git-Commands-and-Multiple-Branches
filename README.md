# 🌳 Practice of Git Commands and Multiple Branches

This repository is created to practice and understand how **Git** works in real development environments.

The focus of this project is not on application code, but on mastering version control operations such as branching, merging, committing, and collaboration workflows.

---

## 📖 Project Purpose

In real companies, multiple developers work on the same project at the same time.  
To handle this efficiently, we must know:

- How to create branches  
- How to switch between branches  
- How to merge changes  
- How to resolve conflicts  
- How to maintain clean commit history  

This repository helped me gain hands-on experience with these concepts.
